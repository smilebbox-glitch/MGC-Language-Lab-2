# MGC Languages v6.0.19 — Factory Journey

Дата: 08.09.2026

## Что изменилось

- Automotive Arcade из 20 игровых механик получил связанный режим **Factory Journey**.
- Пользователь проходит 6 станций автомобильного завода последовательно:
  1. Штамповка — Factory Router.
  2. Кузов / сварка — Car Part Hotspot.
  3. Окраска — Defect Detective.
  4. Сборка — Build the Car.
  5. Качество — Quality Gate.
  6. Логистика — Logistics Flow.
- Следующая станция открывается после завершения предыдущей.
- Для каждой станции показывается лучший результат, общий прогресс маршрута и количество идеальных 5/5.
- Сохранены персональные рекомендации по отделу, Game of the Day и Arcade Passport из v6.0.18.
- Сохранён backend-limit: максимум 5 ответов за одну игровую сессию.
- Словарный паритет не менялся: **2029 Chinese + 2029 English** в runtime.

## UX

Factory Journey визуализирует автомобильное обучение как производственный поток, а не как набор несвязанных карточек. Маршрут адаптивен для desktop/mobile, поддерживает reduced motion и использует только локальные ресурсы.
