# Chinese learning scope — v5.6

## Single primary target
All Chinese learning in the core MGC Languages track is **Putonghua (普通话), standard Chinese**.

This applies to:
- glossary and thematic terms;
- Pinyin and tones;
- audio playback;
- quizzes and games;
- role-play scenarios;
- 30-day course;
- final exam;
- XP awards and learning progress.

## Dialects / regional speech
The dialect section exists only so employees understand why real speech in China can sound different from training material. It is **reference-only**:
- no XP;
- no course completion;
- no final-exam questions;
- no Skills Matrix contribution;
- no requirement to memorize regional transcriptions.

The UI must always state that users are learning Putonghua before showing dialect information.
