# Frontend quality — MGC Language Lab

1. Inspect static/index.html, static/pilot/ and current styles/scripts before editing. Identify which styles are active.
2. Preserve the v6.0.31 user journeys: Home, Topics, Test, Scenarios, 30-day Course, Games, Final Exam.
3. Optimize for low-powered workstations, fast local assets and mobile Safari; avoid large animations, 3D, network fonts and runtime libraries.
4. Verify touch targets, tap/keyboard behavior, contrast, loading/empty/error states and narrow screens.
5. Avoid introducing new competing design themes or resurrecting discontinued menu entries.
6. Run relevant regression tests and document actual render checks and remaining risks.

Compatible concepts: https://github.com/pbakaus/impeccable ; https://github.com/nextlevelbuilder/ui-ux-pro-max-skill ; https://github.com/Nutlope/hallmark. This skill provides project-specific procedures, not the full upstream packages.
