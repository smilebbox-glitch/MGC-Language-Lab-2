# Automotive language learning QA

- Compare Chinese characters, tone-marked pinyin, Russian meaning and technical English for consistency.
- Use domain-specific terms (assembly, body-in-white, welding, coating, battery, parts, quality, logistics) and distinguish literal translations from real industry usage.
- Verify that answer keys, distractors, game scoring and 30-day course tests align with the displayed learning material.
- Avoid pseudo-Cyrillic Chinese pronunciation in pilot scenarios; README specifies characters + pinyin + Russian meaning.
- Respect local/offline operation and never send internal source material to third-party services.
- Report changes to content, tests run, and terms that require native-expert review.
