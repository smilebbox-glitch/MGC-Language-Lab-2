# v6.0.27 — Adaptive Training Loop

## Что изменилось

v6.0.27 превращает результаты игр и Shift Simulation в персональный следующий учебный маршрут. Рекомендация строится на серверной истории текущего пользователя и не зависит от данных других сотрудников.

### 7 компетенций

Adaptive Training Loop использует те же устойчивые группы навыков, что и Arcade Mastery:

- Терминология;
- Аудирование;
- Производство;
- Качество;
- Логистика;
- Инженерия;
- Коммуникация.

### Два источника сигнала

План объединяет:

1. последние завершённые игровые сессии пользователя;
2. сохранённые Shift Review, включая Production control, Prioritization, Production judgement, Language и финальные Line / Quality / Material / Supplier / Team load.

Слабая компетенция считается по нескольким попыткам. Shift Review дополнительно усиливает релевантные навыки: например, слабый Production judgement и слабый Quality health повышают приоритет Quality/Engineering тренировки.

### Ротация вместо фарма

На каждый цикл формируется три шага:

1. основная игра для слабейшей компетенции;
2. другая механика для закрепления того же навыка;
3. Shift Simulation для проверки переноса навыка в связанную производственную ситуацию.

Если конкретная механика уже закрыта на 100%, она получает более низкий приоритет. Непройденные и слабые альтернативы поднимаются выше.

### UI

В разделе «Игры» появился блок `ADAPTIVE TRAINING LOOP · v6.0.27` с:

- текущим учебным фокусом;
- уровнем уверенности рекомендации;
- объяснением, почему выбран этот фокус;
- тремя последовательными шагами;
- количеством игровых результатов и Shift Review, на которых основан план.

После завершения игры компактная версия блока появляется рядом с результатом и Top-10, чтобы пользователь сразу мог начать следующую полезную тренировку.

### API и архитектура

Новый аутентифицированный user-scoped endpoint:

```text
GET /api/adaptive-training/plan?language=chinese|english
```

Endpoint вынесен в отдельный `APIRouter`, подключается через fail-closed router bridge до корневого StaticFiles mount и включён в critical route contract.

### Ограничения и безопасность

- нет нового XP endpoint;
- рекомендация сама по себе не начисляет XP;
- существующий max-5 ответов в игровой backend-сессии не меняется;
- server-side anti-farm остаётся без изменений;
- новая миграция PostgreSQL не требуется;
- данные плана user-scoped;
- Manager/Team Analytics не используется для построения индивидуального плана сотрудника.
