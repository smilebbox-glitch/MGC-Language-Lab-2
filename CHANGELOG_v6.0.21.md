# MGC Languages v6.0.21 — Production Game Depth

## Цель релиза

Углубить существующие 20 игровых механик без создания дублирующих игр и без изменения действующего backend-контракта XP/anti-farm.

## Что изменено

- Добавлен новый слой `game-depth-v621` поверх существующего Automotive Arcade.
- Добавлен выбор сложности: **Адаптивно / Учебный / Смена / Эксперт**.
- В адаптивном режиме пять вопросов автоматически усложняются: 1–2 учебные, 3–4 сменные, 5-й экспертный.
- Для всех 20 игр добавлен отдельный производственный контекст с более реалистичной постановкой задачи.
- Добавлены визуальные сцены:
  - сборочная линия;
  - сварочный Body Shop с роботами и сварочной зоной;
  - окрасочная камера с кузовом, роботами и воздушным потоком;
  - логистический док с грузовиком, паллетами и погрузчиком;
  - Quality Gate / измерительная зона;
  - safety-сцена;
  - инженерный BOM/CAD-стол;
  - склад/рабочий пост;
  - рабочая коммуникация / сменный control room;
  - маршрут по основным цехам завода.
- `Car Part Hotspot` получил более детальную схему автомобиля: линии крыши и пояса кузова, пороги, швы капота/крыла, ручки, решётка, светотехника, ступицы, спицы и стойки остекления.
- Исходные интерактивные hotspot-зоны и обработчики ответов сохранены, поэтому механика не ломается.
- В экспертном режиме уменьшается визуальная помощь и скрывается часть переводных подсказок.
- На карточках игр отображается наличие трёх производственных уровней.
- Добавлена мобильная адаптация новых сцен.

## Что намеренно не изменялось

- Backend game types — по-прежнему 20.
- Игровая сессия — максимум 5 ответов.
- Серверная логика начисления XP и anti-farm.
- Существующие Factory Journey, Daily Missions, Boss Shift и Arcade Mastery.
- API `/api/games/*`.

## Regression guard

`tests/v621_game_depth_test.py` проверяет:

- покрытие всех 20 game types;
- три производственных уровня + adaptive mode;
- обязательные отдельные сцены окраски, сварки и логистики;
- расширенную детализацию автомобиля;
- сохранение исходных hotspot-обработчиков и лимита `max 5`;
- загрузку новых assets до frontend readiness gate;
- JavaScript syntax через `node --check`.
